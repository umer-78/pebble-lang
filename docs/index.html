The language in one screen

let/fn/return, if/else, while/for, numbers are floats, strings, lists [1,2], maps {}, closures that capture scopes, and/or short-circuit and return an operand. Sixteen builtins: print len push split has str num abs min max range and friends.

A closure captures a scope, not a snapshot

let a = "global"; { fn show() { print(a); } show(); // global let a = "block"; show(); // global — the hard part }

Per-iteration bindings

let fns = []; for (let i = 0; i < 3; i = i + 1) { push(fns, fn() { return i; }); } print([fns[0](), fns[1](), fns[2]()]); // [0, 1, 2]

Undefined variables are errors, not nil. Every error names line and column: line 3, column 19: undefined variable 'xs'.
